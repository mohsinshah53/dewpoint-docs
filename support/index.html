SUPPORT

Get help with Dewpoint

Theme support covers installation, settings, sections, bugs and update questions for stores using Dewpoint. Replies come from the developer, usually within one working day (Mon–Fri, UK time).

Read the docs first

Most questions are answered in the documentation, including a troubleshooting list.

Report a bug

Include your store URL, the page, the browser and a screenshot. Bugs are fixed in theme updates at no charge.

Customisation

Setting-level customisation is covered. Custom code changes are quoted separately.

Contact

Use the form below, or email mohsinshah53@gmail.com. Please add a collaborator request for your store if you need us to look inside the theme editor; we never ask for your password.

Support is provided directly by the theme developer. Dewpoint is an original theme and is not affiliated with Shopify; for billing, orders or your Shopify account, contact Shopify Support.
