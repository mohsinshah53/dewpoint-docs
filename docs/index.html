Dewpoint theme docs

Everything you need to install, customise and launch Dewpoint. If something is missing, ask support and we'll add it here.

01Install

  1. In Shopify admin go to Online Store → Themes. If you bought Dewpoint from the Theme Store it is already in your library; otherwise choose Add theme → Upload zip file.
  2. Click Customize to open the theme editor, or Publish when you are ready.
  3. Dewpoint shows its own illustrated demo imagery wherever you have not yet chosen an image, so the store looks finished from the first minute. Turn this off before launch under Theme settings → Demo imagery.

02Demo content

The demo pack (products CSV, images and a setup guide) recreates the demo store. Import products.csv under Products → Import, upload the images under Content → Files, then attach them to products and collections. Full steps are in DEMO-STORE-SETUP.md in the pack.

03Theme editor basics

  • Sections are added from the left panel with Add section. Every section has a colour scheme, top/bottom padding and, where useful, a "Show top rule" toggle for the hairline that separates sections.
  • Section index numbers (01, 02, 03…) are automatic. Turn them off globally under Theme settings → Layout → Number sections.
  • Accent words: in any heading field, italicise a word (the I button) and it renders in the accent serif font. Example: Skin at its dewpoint.
  • Dynamic sources: text, richtext and image settings accept metafields via the connect icon, which is how you show per-product formula data.

05Home page recipe

The demo home page, top to bottom: Slideshow → Ticker → Featured collection → Collection list → Formula index → Lookbook → Before/after → Testimonials → Promo ticket → Image with text → Values → Journal → FAQ → Newsletter. You can reorder or remove any of them.

Lookbook hotspots. Each hotspot block has a product and an X/Y position (percent). Hover or focus a marker to highlight its row; rows add straight to the bag.
Promo ticket. The discount code shown on the ticket is copy-to-clipboard. Create the matching code under Discounts in Shopify admin; the theme only displays it.

06Product pages

The product template is built from blocks you can reorder: specimen label (type, vendor, SKU, rating), title, price, text, variant picker, buy buttons (quantity, dynamic checkout, pickup availability, gift-card recipient form), stock status, description, collapsible rows, key actives, icon claims, share, complementary products, and app blocks.

  • Key actives rows use one line per ingredient in the form Name | Value. Connect a multi-line text metafield to make it per-product.
  • Shade swatches appear automatically for options named Colour, Color or Shade. Add swatch colours or images to option values under Settings → Custom data → Categories, or the theme falls back to the value name as a CSS colour.
  • Ratings display when a reviews app writes to the standard reviews.rating metafield.
  • Complementary products come from the Shopify Search & Discovery app.
  • Gallery layouts: stacked ledger (two-and-one grid), carousel, or carousel with thumbnails. Zoom opens a full-size modal.

07Collections & filters

Install the free Search & Discovery app and enable filters (availability, price, product type, tags, options). The collection page shows them in a drawer or, on desktop, an optional sidebar. Filtering, sorting and pagination update without a page reload. Promo tiles can be inserted at any grid position from the section's blocks.

08Menus & mega menu

Assign the main menu in the header section. Three levels are supported. To turn a top-level item into a mega menu, add a Mega menu block to the header and type the item's title exactly; its sub-menus become columns and you can add a promo image and link. The mobile drawer mirrors the same menu.

09Cart & checkout

Choose drawer or page under Theme settings → Cart. The free-shipping progress bar uses the threshold you set there (in store currency, no symbol) and should match your shipping rates. Order notes, cart-level discounts, unit prices and recommendations are supported. Dynamic checkout buttons (Shop Pay, PayPal, etc.) appear on product pages and the cart.

10Pages, blog and contact

Two page templates are included: page.contact (contact form with detail rows and an FAQ) and page.faq (grouped questions with FAQ structured data for search engines). Assign them from the page's Theme template dropdown. Blog posts support reading time, tags, sharing and comments.

11Launch checklist

  1. Turn off Theme settings → Demo imagery.
  2. Set the favicon and social links.
  3. Check the free-shipping threshold matches your rates.
  4. Replace the Ticker claims and the Promo ticket code with your own.
  5. Fill shop policies (Settings → Policies); the footer lists them automatically.
  6. Run Lighthouse on home, collection and product pages.

12Theme settings reference

Colours

Dewpoint ships five colour schemes. Each scheme defines nine roles:

  • Background background
  • Text text
  • Secondary text muted
  • Rules & borders line
  • Accent accent
  • Text on accent accent_contrast
  • Highlight (sale badges, stamp) highlight
  • Button button
  • Button text button_text

Pick a scheme per section with its Colour scheme setting. Keep background/text pairs above a 4.5:1 contrast ratio; the defaults all pass.

Performance & accessibility

Dewpoint uses no frameworks: three deferred JavaScript files totalling about 25 KB unminified, one preloaded stylesheet, responsive images with srcset, lazy loading below the fold and font preloading with font-display: swap. Drawers and modals trap focus, Escape closes them, all controls are keyboard-operable with visible focus rings, colour schemes ship at WCAG AA contrast, and animations respect the reduced-motion preference.

Troubleshooting

Demo product cards link to a page that doesn't exist

Assign a real collection to the section, or import the demo products CSV so the handles resolve.

Filters don't appear on collection pages

Install the Search & Discovery app and enable at least one filter. The drawer hides itself when there are no filters.

Pickup availability is missing on the product page

Enable local pickup for a location under Settings → Shipping and make sure the variant has stock at that location.

Swatches show as grey circles

The option value name isn't a recognised colour. Add a swatch colour or image to the option value under Settings → Custom data, or rename the value (e.g. "Rose" → "#d79a8b" is not needed if you use swatches).

The accent font isn't italic

Choose an italic style in Theme settings → Typography → Accent font; the picker lists weights and styles per family.

I see "Opening soon" on my store

Password protection is on. Development stores keep it until they move to a plan; other stores can turn it off under Online Store → Preferences.
